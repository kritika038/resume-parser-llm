## 🎓 How to Use

### For Users
```bash
# Run the application
streamlit run app.py
# Open browser to http://localhost:8501
```

### For Developers
```python
from services import extract_pdf, parse_resume, calculate_ats_score
from services import match_with_jd, generate_suggestions

# Extract PDF
text = extract_pdf(pdf_file)

# Parse resume
parsed = parse_resume(text)

# Calculate scores
ats_score = calculate_ats_score(parsed)
jd_score, matched = match_with_jd(parsed["skills"], jd_text)

# Generate suggestions
suggestions = generate_suggestions(parsed, jd_text)
```

### For Integrators
```python
# Use services directly in your application
from services import parse_resume
from services.ats_scorer import calculate_ats_score

result = parse_resume(resume_text)
score = calculate_ats_score(result)
```
