## Reporting a Vulnerability

We take the security of our platforms seriously. If you find any vulnerabilities or security issues in this repository, please do not open a public issue. Instead, report it privately to the maintainers:

1. Draft a detailed security report outlining:
   - The location of the security vulnerability
   - Steps to reproduce or exploit
   - Potential impact
2. Email the report to: `maintainers-security@example.com`

We will review your submission and respond within 48 hours to coordinate a patch and release timeline.
